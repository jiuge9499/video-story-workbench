# 视频故事工坊

本机视频制作工作台：输入口播文案，生成分镜图片、配音字幕、1080P 视频、3:4 首图及发布文案。

## 启动与使用

用户于 2026-11-09 确认的制作标准保存在 `lib/production-method.json`。文案清理、首图方法和人物表情方法均在实际使用时读取，后续新制作自动执行；已确认成片和首图保留。

双击 `打开视频故事工坊.command`，打开 http://127.0.0.1:8776。重复打开会连接已有服务。

可一次选择多条作品加入队列，按入队顺序启动，同时最多制作两条视频；每条最多同时生成四张图片，全局最多同时生成八张（含首图）。当前作品有固定人物与画风参考图时可直接并行出图，否则先确定首张参考图；后续图片最多四张并行生成；配音字幕与图片同步制作；本机配音和视频合成各保留一个名额，素材齐全后排队合成。同一作品的任务不会重叠执行。高级编辑支持导入图片、锁定画面、调整镜头、声音、字幕与转场。

关闭浏览器不会停止制作；退出服务或关机会暂停。下次启动后，完整制作任务自动恢复排队，只补未完成部分；明确取消的任务不会恢复。不会自动创建示例作品。

## 删除作品

在“我的作品”的卡片中点击“删除”，或在编辑页右上角点击“删除作品”。确认后删除文案、制作记录和未被其他作品引用的素材；正在制作或排队的作品需先停止任务。删除后界面自动清除旧视图。

页面上方显示紧凑制作进度与默认折叠的制作记录，下方为文案或成片。制作任务按作品合并显示，旧任务折叠到历史记录，当前任务的停止和恢复入口保留。

## 失败恢复

图片成功后立即保存，失败镜头留到其他镜头完成后补试。连接故障采用有限次数退避重试。单条内容或本地错误标为“待恢复”，继续后面的作品。登录、限额或持续网络故障使队列等待恢复，每 5 分钟尝试一次，也可点击“现在重试”或取消等待任务。

已完成素材复用。修改台词、声音、图片或包装参数，会按依赖关系更新对应输出。历史成片不会被当作修改后的最新版本导出。

## 声音与画面

所有视频风格全程在左上角显示“跃龙教育”名称水印，距左侧 48px、顶部 40px，32px 白字配半透明深色底。水印在视频合成时统一叠加；原有成片需重新合成后才会带水印，图片和配音可复用。

口播目标 -18 LUFS，背景音乐 -25 LUFS；说话时音乐最多额外降低约 3 dB。音乐淡入 0.6 秒、淡出 0.8 秒。配音压缩长停顿并同步字幕时间。默认使用根目录 `背景音乐.mp3`。

默认采用已确认的 B5：图片在每镜内从 100% 匀速放大到 114%，无回缩、弹跳或重点句二次推近；手动固定画面仍保持静止。开场分条进入，标题停留约 2 秒，单次“噔”带约 1.2 秒渐弱尾音。默认音效音量 12% 对应 B5 的确认音量，也可关闭或调整。旁白与字幕同步延后 0.12 秒，成片字幕导出及镜头跳转使用同一偏移。

混音按目标时长限定采样数，并限制最终文件时长和大小，异常时删除未完成的音轨。

转场以叠化为主，普通换图不配音效。详细规则见 `转场方法.md`。成片为 1920×1080、30 帧/秒；右下角固定提示字号为 28px，保留与底部字幕的间距。

发布正文直接围绕视频内容展开，不添加“原文提到”“需要进一步核实”等审稿式说明，不强化未经核实的结论。发布素材需人工验收，不自动发布。

## 保留目录

- `server.mjs`、`launcher.mjs`、`lib/`：服务、调度和制作逻辑。
- `public/`：页面、字体、试听音色与音效。
- `.runtime/`：工作台 Python 环境及固定视频渲染器，是运行依赖。
- `data/state.json`：作品与任务记录；`data/media/`：图片、音频、成片和发布素材。

运行需要本机 Node.js、FFmpeg、FFprobe，以及已登录的 Codex CLI。可通过 `PORT`、`STORY_CODEX`、`STORY_PYTHON`、`STORY_HYPERFRAMES`、`STORY_DATA_DIR` 覆盖默认配置。服务只绑定 127.0.0.1，写请求校验本机来源和会话令牌。

渲染器有本地 AAC 峰值校正补丁：2 dB 余量、最多 6 次校正，仍执行 -1 dBFS 峰值验收。重装渲染器依赖时需检查该补丁。

## 数据清理

2026-10-31 已按要求清空所有作品、任务及媒体数据，并清理调试试片、临时验证文件和过期素材。B5 正式音效及运行依赖保留。此为一次性清理，不会自动删除后续制作的作品。

字幕默认白字、纯黑描边。按原文标点、完整词和口播停顿组织短句；长句采用均衡分组，避免句尾剩一两个字。引号按开闭归属附着，SRT 与画面共用同一份逐词时间轴。字幕规则更新时可复用原始配音缓存重排，不重新请求配音服务。

## 学生服装基准

所有作品的学生默认使用已确认南宁秋季校服。统一配置位于 `lib/costume.mjs`，基准图位于 `data/media/shared/characters/nanning/student-boy-v1.png`。分镜和每次出图均带具体服装要求；出图始终以固定基准图为第一参考，仅使用带同款版本标记的镜头保持连续性。缺少基准图会明确报错，不回退旧款。已有成片需更新图片并重新合成后才会改变。

## 视频风格

新增「写实手绘图解」：米白纸底、钢笔轻排线、灰粉淡彩与青绿赭棕点缀，适合老师个人 IP 的教学和机构运营内容。两张本人照片固定五官与发型，已确认样图固定画法；参考素材保存在 `data/media/shared/characters/teacher/` 和 `data/media/shared/styles/realistic-handdrawn-v1.png`。每次出图同时带本人照片、画风基准和同片合格镜头，旧版或其他风格镜头不会被当作连续性参考。老师默认粉色外套与黑色内搭，图中不重复绘制标题和字幕。

新风格沿用故事插画的 B5 开场、100%–114% 匀速放大、原字幕、音效、背景音乐、共享配音及转场流程，只增加图片风格选项。3:4 首图沿用同款米白手绘和深色标题。原有作品和其他风格设置保持原样。

在“提交与验收”页，完整口播文案下方、配音音色上方选择“故事插画”或“教育卡片”；高级文案页右侧也有同一入口。教育卡片支持打开15秒横版样片，采用无Logo、无吉祥物、无陪练提示的简洁图解。教学例句可正常包含英文。

故事插画沿用原有校园插画和B5合成。教育卡片使用米白青蓝配色、固定配图、分步文字进入和浅底字幕，并使用简洁排版与米白青蓝配色参考，不套用学生校服。风格分别影响分镜提示、出图、视频合成和首图。

更换风格后，未锁定镜头的当前图片与画面描述会清空以便重做，历史图片版本保留；锁定镜头不变。旁白和配音缓存可继续复用。原有作品默认保持故事插画，已有成片有效性不受这次功能更新影响。

## 本机共享配音

配音同时提供本机克隆音色和原有在线音色，默认仍为“男播客”、语速 1.0。本机音色调用相邻工程 `ai-wenzi-workflow-main/src/mine/voice_service/client.py`，共享服务中的新音色会自动同步到工作台并缓存到 `data/shared-voices.json`。已新增“女博客”，来自用户指定的微信视频，并提供新文案试听。客户端自动启动服务；模型、环境和句内最多三次读音检查均由共享服务管理，不另装或启动一份语音模型。可通过 `STORY_VOICE_CLIENT` 指向其他位置的统一客户端。

Emma、Ava、Vivienne、Seraphina、Thalita、云扬、云健、云希、云夏、晓晓、晓伊已恢复为独立可选的在线音色。在线配音复用工作台已有 `edge-tts`，按文案、音色和语速缓存音频，并复用已有 Whisper 检查与字幕对齐；不替换成其他音色。本机音色和在线音色均保持原来的音量、停顿压缩、字幕和视频流程。

最终文案来自作品 `script`；生成前校验分镜旁白逐字匹配（忽略空白）。已恢复的在线音色不再自动切换为“男播客”，音色和语速严格按作品选择执行。更换音色会使旧配音过期，已有图片不受影响；未更换音色的旧作品保持原设置和缓存。

保存文案、开场标题和分镜时，清除成对的 Markdown 加粗标记（`**`、`__`），保留其中正文；配音入口再次清理后才计算请求缓存并生成音频和字幕，避免格式符号进入朗读和画面。

输出仍在 `data/media/<作品ID>/jobs/<任务ID>/speech/`：`final-script.txt` 为最终文案快照，`speech-N.mp3` 为服务原始音频，`narration.wav` 为交给后续合成的完整配音，`speech.json` 为镜头、字幕与读音提醒，`service-jobs.json` 记录共享服务任务编号。已有 Whisper 为新音频测量字符时间，压缩停顿时同步调整字幕；语速由服务统一处理，不重复变速。

字幕时间对齐使用 macOS 内置 ICU 将原文和识别结果统一为简体后比较，并按数值匹配中文整数与阿拉伯数字（如“四千一百”和“4100”），保留原文显示和每字时间；字形和相同整数的写法差异不会触发低匹配率暂停，真正的内容和数值差异仍按原阈值检查。

`data/media/<作品ID>/voice-requests/` 持久保存防重复编号，由文案、音色和语速生成。网络重试、等待超时、工作台重启复用原编号和后台任务；超时不取消服务任务。服务明确失败时使用新编号，单次最多尝试两个服务任务；仍失败则保留记录并暂停后续步骤。文案、音色或语速改变会生成不同编号。

退出码 0 代表生成与检查通过，2 代表音频已保存但需复核，1 代表执行失败。`speechIssue` 将失败或读音提醒写入作品，阻止后续视频合成、发布素材生成及导出；已生成音频仍可试听。自动读音检查存在识别误差，检查通过不等于人工听感验收。存在读音提醒时，重复调用不会绕过复核或无限生成；应处理提醒或修订文案后重新制作。

## 首图方法

首图生成读取 `lib/cover-method.txt`，参考已确认的“首图编辑”方法，按内容在黑黄观点海报、亲切手账、人物讲解、人文杂志、蓝白科技、蓝黄知识海报中选一种主风格。保持本作品角色，突出一个大标题、一个互补看点及一组主题道具，文字与插画一次生成完整3:4封面；不再后贴固定栏目名或统一大标题。写实手绘作品沿用老师本人，不替换为九歌人物。首图版本6，旧成品保留，新生成素材按新方法执行。

每条视频重新根据内容选择风格；“初二掉分”的黑黄大字是观点纠偏类示例，不能套给所有题材。首图方法在生成文案和生成图片时分别读取，变更后下一次任务自动应用。

## 人物表情

分镜规划和实际出图读取 `lib/character-expression-method.txt`。固定老师的身份、五官、年龄与服装，表情、视线、姿态和手势随情节变化：发现问题时认真或担忧，分析时专注，交流时耐心倾听，纠偏时坚定，取得进展时欣慰。学生和家长分别按自身处境表现情绪，不要求全体同时微笑。参考照片和旧图只锁身份与画法，不复制固定笑脸；新规则优先于旧风格中的“自然微笑”。

每张新生成图片保存实际提示词和制作标准快照，供后续逐镜核对；当前已确认成片不会因为方法更新而自动重做。

## 教育图解画面修正

教育风格采用主画面图解＋底部字幕：取消整段旁白大标题、页眉重复标题和镜头编号。分镜图按语义使用图形、图标、自然家长与学龄孩子动作；禁止Logo、吉祥物和低幼陪练提示。更换渲染版本会使旧的教育文字卡片成片过期；已重新合成的版本使用新的渲染标记。
