# 视频故事工坊

本机运行的视频制作工作台。双击 `打开视频故事工坊.command`，或在此目录运行 `PORT=8776 npm start`，打开 http://127.0.0.1:8776。

## 使用

1. 新建作品，输入主题或完整文案。可用本机 GPT 起草文案、规划分镜，也可直接按段落拆分。
2. 在「声音」中试听六种中文音色、选择音色和 0.8–1.5 倍语速。
3. 在「分镜制作」编辑台词、画面描述、运镜；生成缺图或导入 PNG/JPG/WebP。图片锁定、历史版本和镜头排序可单独调整。
4. 点击「生成视频」，自动生成配音、实际时间字幕、镜头时长，检查后合成 1080P MP4。
5. 「成片预览」可播放、查看历史版本，导出视频、SRT、首帧封面画面和文案。封面画面是成片抽帧，文案导出为作品标题和旁白，尚未自动编写营销文案或3:4封面。

「成片预览 → 画面转场」可选择柔和叠化或直接切换，叠化时长为 0.2–0.8 秒。新作品默认 0.4 秒叠化。转场围绕配音切点对称重叠画面，保持配音、字幕时间与成片总长不变；短镜头会自动缩短重叠范围。更改转场后需重新合成。

修改文案、声音、速度、画面、运镜或字幕后，旧视频会保留但不能作为最新成片导出。标题、图片描述及锁定状态不改变现有成片。每个作品在排队或生成时暂时禁止编辑；其他作品可以继续编辑。最多同时推进 2 个作品；视频、首图及画面检查共用 1 个渲染名额，图片全局逐张生成，失败不会自动改用收费接口。

## 本机依赖

- Node.js（此机现有 Node 20 已跑通）、FFmpeg、FFprobe。
- Codex CLI 使用本机 ChatGPT 登录。文本通过 `codex exec --output-schema`；出图通过内置 image_gen。使用现有用户配置，不读取或复制认证令牌。只在点击相应任务时调用。
- 在线中文配音使用已安装的 `edge_tts`。默认使用本工程 `.runtime/python/bin/python` 的独立环境，不再依赖其他工作流。
- 视频使用 `.runtime/hyperframes` 固定的 HyperFrames 0.8.120 及完整依赖，真实渲染前执行 `check`。HyperFrames 使用额度暂无法读取。

可通过环境变量覆盖 `STORY_CODEX`、`STORY_PYTHON`、`STORY_HYPERFRAMES`（指向 CLI 的 dist/cli.js）、`STORY_DATA_DIR` 与 `PORT`。本应用无额外 Node 运行依赖。字体与 GSAP 来自本机已验证样片，仅用于本机工作流。

## 数据与恢复

`data/state.json` 原子保存作品、任务、验证状态；`data/media/<作品>/jobs/<任务>/` 存放真实配音、时间戳、图片、合成、字幕和记录。停止任务会终止本地进程组；远端请求可能已经完成，不会自动盲目重试。已入库图片保留。重启时活动任务标记为「已中断」，可核对后重试。关闭浏览器不停止服务；服务退出或关机中断任务。

配音按镜头合成，以 -45 dB 检测静音；首尾分别保留约 0.06 / 0.14 秒，内部超过 0.45 秒的静音压缩至约 0.28 秒。自然短停顿保留，字幕与镜头时间同步重算。旧配音会在重新合成时更新，优先复用本地原始配音。图片仍需人工检查角色与手部。自动图像能力以设置页的实际成功任务为准；登录成功不等于图片能力已经验证。

仅绑定 127.0.0.1，写请求校验本机来源和会话令牌，文件路径限制在素材目录，上传图片实际解码，渲染参数使用白名单。诊断日志只留本地，不通过素材接口公开。

## 验证

`npm test`：内容指纹、修改影响范围、路径保护、HTTP 请求隔离、版本冲突、持久化和重启中断恢复。

实现参考：本地已确认的 A+C 设计；[Codex 非交互调用](https://learn.chatgpt.com/docs/non-interactive-mode)、[内置图片生成](https://learn.chatgpt.com/docs/image-generation)。

### 节奏与音效（2026-10-24）
已接入确认过的15秒试片节奏：结论冲入、停稳阅读、重点短句强调。开场最长4秒，短首镜头自动缩短；标题留空时提取首镜头第一句，也可手填不超过40字的核心结论。普通镜头由快速进入转为停稳，设为静止的镜头不额外推近。配音字幕中包含疑问、转折、数字或步骤的短句，按真实字幕起点少量添加重点卡；间隔至少6秒，卡片在本镜头内结束。这是保守文字规则，尚不是自动理解画面或逐字对齐。

音效复用已确认增强版的开场呼啸和标题冲击；面板12%对应呼啸0.70、冲击0.35的素材增益，保留总音量0–30%和关闭选项。普通换图不自动配声。配音不变，修改画面包装无需重新配音。每版保存rhythm-plan.json和transition-plan.json，便于核对时间点。新节奏会在下次合成时应用；旧成片保留，因渲染规则更新标记为需重新合成。

### 一次提交，最终验收
首页只需完整文案与音色。点击一键制作后，自动规划分镜、生成缺图、配音、合成视频、制作1080×1440首图、整理小红书标题/正文/标签。高级编辑保留分镜和参数控制。文案变化会自动重排分镜，旧分镜会留存任务备份。
验收页提供视频、3:4首图下载及标题/正文/标签单独复制或整篇复制。流程五阶段全部完成才到100%。网络和超时故障每阶段最多重试两次；额度、登录、内容格式等问题停止并显示原因，不无限重试。关闭页面不会终止本地制作，关闭电脑或服务仍会中断。

配音兼容性修复：工作台优先使用 `lib/python-packages` 内的 edge-tts 7.3.0，修复旧版本 7.2.8 被服务端拒绝（403）的问题，不修改参考工程环境。重装命令：`"$STORY_PYTHON" -m pip install --no-deps --target lib/python-packages edge-tts==7.3.0`。

### 右下角固定提示
成片全程显示“本视频不涉及培训内容，请勿误判”，位于右下角，采用18px小字、轻微模糊（0.65px）、70%白字与淡底，避开底部中文字幕。下次生成或重新合成生效，历史成片保留。

### 默认背景音乐
使用工作台根目录的 `背景音乐.mp3`，每次合成将配乐处理为独立本地音轨。音乐循环铺满全片，标准响度 −26 LUFS（口播 −18 LUFS），并用口播信号轻度压低配乐（最多约3dB，保留可听见的音乐底）；开头0.6秒淡入、结尾0.8秒淡出。缺失音乐时明确报错。规则在下次生成或重新合成生效，既有配音可复用。

工作台内的生成请求使用官方HTTPS地址及现有ChatGPT认证，避免当前网络下WebSocket路由超时；仅对子进程生效，不改全局配置、账号或模型。任务根目录和每张图片输出目录使用真实路径，避免迁移兼容链接被执行器拒绝。继续制作仍只生成缺图，已入库图片保留。

### 多视频制作队列
在「我的作品」选择多个已有文案的作品，点击「批量加入队列」。空文案或正在制作的作品不能重复入队；批量提交分别报告成功与跳过原因。「制作任务」集中显示每个作品的阶段、进度、等待原因，可分别查看作品、停止或重试。

默认同时推进 2 个作品；文字请求最多 2 个，图片、配音各 1 个，视频与首图共用 1 个渲染名额。视频内部仍使用 2 个渲染工作进程。等待名额时可以取消，失败和取消都会释放名额。系统内存压力达到严重级别时，暂缓启动新作品与渲染，现有步骤继续完成，压力恢复后自动推进。

更新服务必须等所有制作与排队任务结束。并发验证使用临时数据和模拟生成工具，不消耗正式出图、配音额度；实际多视频耗时仍以日常使用为准。

### 订阅额度记录（2026-10-27）

每次制作任务实际开始前和结束后，工作台通过本机 Codex 的官方 `account/rateLimits/read` 接口自动读取账户订阅用量，不发起模型生成、不读取或复制认证令牌。快照、时间和对比结果保存在 `data/state.json` 的任务记录内。作品的「本作品订阅额度记录」、我的作品和制作任务页显示用量；设置页显示最近查询的剩余额度，点击重新检查可刷新。

记录为账户已用百分比的变化，单位是「百分点」，按返回的周／小时窗口分别比较；不会换算成 API 金额。每条作品累计仅包含没有工作台内任务重叠、账户与套餐一致、窗口可比较的任务；失败或取消但有完整快照的任务也会保留并计入。并行任务的差值包含共享消耗，只展示、不相加或分摊。其他聊天、其他进程或设备的消耗无法排除，因此属于制作期间账户变化，不能保证单条视频的独占消耗。

查询失败最多等待12秒，随后继续制作；结束快照失败不改变制作成功状态。跨额度重置、账户切换、用量回落或服务中断不生成虚假的消耗值。服务端数据可能取整或延迟，显示无变化不代表零消耗。历史任务没有前后快照，无法追溯补算；取消排队的任务没有实际开始，不记录制作快照。原有并发上限保持不变，若需要更易归因的样本，请单条制作，并尽量避免同时使用其他消耗同一额度的任务。

### 制作用时记录（2026-10-29）
作品页面原额度记录面板改为「制作用时记录」，显示累计制作时间、每次任务耗时和开始/结束时间，运行中每秒更新。沿用已有任务的 started / finished 记录，因此可显示有完整时间的历史任务。计时不含任务开始前排队，包含任务运行期间的资源等待、重试及额度查询时间；失败或停止的已运行任务也计入累计。服务中断的结束时间无法确认，显示未知，不计入累计。底层订阅额度记录继续保留。
